PointTrigger / PointTrigger3D

Description:
A simple trigger that calls a method, plays an animation, plays sounds, and optionally loads a scene when a body enters the area or when clicked. Drag any node into the target field — a dropdown of its available methods appears automatically.

Variants:

  • PointTrigger — Extends Area2D. Add a CollisionShape2D or CollisionPolygon2D child.
  • PointTrigger3D — Extends Area3D. Add a CollisionShape3D child.

Properties:

  • target_node: NodePath — Drag any node from the scene tree into this field.
  • target_method: StringName — Method to call on the target node. Once target_node is set, the inspector shows a dropdown of all available public methods on that node.
  • animation_player_path: NodePath — Path to an AnimationPlayer node.
  • animation_name: String — Name of the animation to play. Once animation_player_path is set, the inspector shows a dropdown of all available animations.
  • sounds: Array[AudioStream] — Audio streams to play simultaneously when triggered.
  • scene_to_load: String — Path to a .tscn scene to load after triggering.
  • trigger_once: bool — If true, the trigger can only fire once.

Signals:

  • trigger_started — Emitted when the trigger activates.
  • sounds_played — Emitted when sounds are played.
  • animation_played(name: String) — Emitted when an animation is played.
  • method_called(method: StringName) — Emitted after the target method is called.
  • scene_changed(path: String) — Emitted after the scene is changed.

Usage:

  • Add as a child of your scene.
  • Add a collision shape child (and offset it to overlap with the player).
  • Set monitoring = true on the Area node.
  • Drag a node into target_node — select a method from the dropdown.
  • Optionally set an animation_player_path and pick an animation.
  • Add sounds to play on trigger.
  • Triggers on body enter or mouse click.

Example — Turn on lights when player walks in:

# Set target_node to your light node
# Set target_method to "show" or "set_enabled"
# Set animation_name to "light_on" if you have an AnimationPlayer
